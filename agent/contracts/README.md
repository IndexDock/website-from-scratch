# Workflow contracts

Contracts define requirements that apply across phases. Phase modules say what to do now; these files say what a correct result must satisfy.

- `orchestration.md` controls the one-task experience and bounded delegation.
- `state.md` controls durable workflow state, generated status, and decision records.
- `scope.md` controls what Starter accepts, simplifies, or refuses.
- `content-integrity.md` controls evidence, anti-invention rules, and page purpose.
- `assets.md` controls learner-supplied and generated visual assets.
- `icons.md` controls the one vendored icon system and bans emoji, dingbats and text arrows.
- `typography.md` controls the three leading tokens every `line-height` goes through and requires display headlines to be shaped.
- `discoverability.md` controls metadata, SEO, baseline AEO, schema, and navigation aids.
- `quality.md` controls hard publication requirements and quality targets.
- `attribution.md` controls the Starter credit.
- `git-delivery.md` controls session branches, checkpoint pushes, and automatic promotion to `main`.
- `cloudflare-deployment.md` controls learner Cloudflare setup and Workers Builds deployment.
