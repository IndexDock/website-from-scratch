# Scope

## Goal

Return `accepted`, `accepted with simplification`, or `not suitable` using a short interview.

## Actions

- Apply `agent/contracts/scope.md`, `agent/contracts/state.md`, and `agent/contracts/orchestration.md`.
- Ask two required questions:
  1. What is your occupation or business, and what should the website help it achieve?
  2. Who should visit the website, and what must those visitors be able to do?
- Ask at most two conditional questions only when the answer affects suitability.
- Offer a public marketing-site reframe when an app request can be simplified safely.

## Exit

Save the result and rationale in `project/SCOPE.md`, append the decision, and set `approvals.scope` only after explicit scope approval. Continue only after that approval is durably recorded.
